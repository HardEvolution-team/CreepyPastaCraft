# CreepyPastaCraft Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **CreepyPastaCraft (Revived)** by Phuck_Yu_too, adopted by The_NetZ.

- Original: https://forums.minecraftforge.net/topic/14637-/
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.33.0+

This port contains **no original assets**. Put your own copy of the original jar (`creepypastacraft_revived_mod_1.7.10.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
